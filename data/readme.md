# Data and Datasets

This file documents the data KIBA-D is using, both input and reference data, as well as the different data splits and
versions. It also aims to document remote copies and reference sources for the individual data items.

## DFKI cluster

The main data folder on the DFKI cluster is `/ds/text/kiba-d/`. It contains the following data folders:

| Folder                    | Type                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:--------------------------|:-------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| zotero_literaturdatenbank | Source (PDFs)            | Contains 3917 PDF files for publications from from the [Faktencheck Artenvielfalt Literaturdatenbank](https://www.zotero.org/groups/4699059/faktencheck_artenvielfalt_literaturdatenbank) that are digitally available, provided by iDiv. PDFs are labeled by their Zotero Item ID, which is also the main key in the Postgres version of the literature database managed by FEDA. The folder is synched with https://cloud.dfki.de/owncloud/index.php/s/AC2XCHfDoza2rkb. See also the synch script https://github.com/DFKI-NLP/kibad-llm/blob/main/src/kibad_llm/data_integration/synch_nextcloud_with_cluster.py.                                                                                                                                           |
| semantic_scholar          | Metadata (JSON) and PDFs | (**TODO add more details here**) Metadata and PDFs retrieved via SemanticScholar as part of our crawling pipeline. See https://github.com/DFKI-NLP/kibad-crawler                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |                   
| splits                    | Source (PDFs)            | train/dev/test/unlabeled splits created from the data in `/ds/text/kiba-d/zotero_literaturdatenbank`, for which PDFs were available. See issue https://github.com/DFKI-NLP/kibad-llm/issues/129 for statistics and the actual script used to create the splits.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| dev-set-100               | Source (PDFs)            | The original development set used for the core schema evaluation of the KIBA-D pipeline. Synched with https://cloud.dfki.de/owncloud/index.php/s/eZQCLcbPFXCf6E3 . See https://github.com/DFKI-NLP/kibad-project-management/issues/2#issuecomment-3350854943                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| dev-set-Wald-WVC          | Source (PDFs)            | The original development set used for the OrganismTrend schema evaluation of the KIBA-D pipeline. Contains all PDFs used in the weighted vote count evaluation for the Forest habitat/chapter (see https://github.com/DFKI-NLP/kibad-llm/blob/main/data/external/organism_trends/Weighted%20Vote%20Count%20Wald%20Literatur%20-%20Sheet1.csv, except rows with #NV), plus all additional publications with no trends that were cited in the Forest chapter of the Faktencheck Artenvielfalt. See https://github.com/DFKI-NLP/kibad-llm/issues/168. See https://cloud.dfki.de/owncloud/index.php/s/XoFaJ3r65m74o8Y for additional PDFs for WVC trends that are not included in the Zotero literature DB.                                                       |
| dev-set-Wald-178          | Source (PDFs)            | A subset of the dev-set-Wald-WVC containing a sample of the PDFs used in the weighted vote counte evaluation for the Forest habitat/chapter. See issue https://github.com/DFKI-NLP/kibad-llm/issues/139                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| test-set-AuO-WVC          | Source (PDFs)            | The original test set used for the OrganismTrend schema evaluation of the KIBA-D pipeline. Contains all PDFs used in the weighted vote count evaluation for the Agrarian and Open Landscapes habitat/chapter (see [here](https://github.com/DFKI-NLP/kibad-llm/blob/main/data/external/organism_trends/Weighted%20Vote%20Count%20Agrar-%20und%20Offenland%20Literatur%20-%20Sheet1.csv)), plus a random sample of 225 additional publications with no trends that were cited in the Agrarian and Open Landscapes chapter of the Faktencheck Artenvielfalt. See https://github.com/DFKI-NLP/kibad-llm/issues/538. See [here](https://cloud.dfki.de/owncloud/index.php/s/XoFaJ3r65m74o8Y) for additional PDFs for WVC trends that are not included in the Zotero literature DB. |
